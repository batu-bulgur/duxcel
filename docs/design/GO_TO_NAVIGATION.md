# Same-sheet Go To navigation

The finite controller parses one complete address through the existing Grid address parser. It rejects embedded NUL, overlong input, names, ranges and out-of-sheet coordinates without changing the output. Applying a target grows column capacity through the checked Grid path before changing selection, then settles programmatic reveal after row-gutter layout. Existing widths and physical names survive growth; new capacity is default-width and unnamed. This operation has no CellStore, history or query authority.

The initial App profile is a manual, source-free, object-free sheet. Connected sources, analytical results and whole-axis selection remain outside this child. The planned entry points are the address strip and primary-modifier G, with an owned modal draft and actual document/sheet session fences. Invalid input and allocation failure must retain that draft and the prior selection/view.
