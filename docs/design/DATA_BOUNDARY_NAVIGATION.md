# Manual data-boundary navigation

The initial C01 profile covers finite cell selections on actual source-free, object-free manual sheets. Cmd/Ctrl+Arrow follows a contiguous occupied run to its far edge when the starting cell and adjacent cell are occupied. Otherwise it skips the blank gap to the first occupied coordinate in that direction, or the fixed physical sheet edge when none exists. Repeated presses traverse island edges and gaps. A viewport Page or used-range boundary is never treated as the data boundary.

Stored presence is occupied, including SQL NULL and present empty Text. Sparse absence and formatting-only coordinates are blank. Literal text beginning `=` remains literal text; this slice adds no formula engine or Excel Mac occupancy/parity claim.

Non-Shift starts from the active cell and collapses the selection at the target. Shift starts from the moving end and preserves the fixed anchor. The active cell remains inside the extended rectangle; when a reversal excludes it, it returns to the anchor, matching existing Grid extension behavior. Whole-axis selections, source/Table/Pivot/unknown results and uncached analytical extents remain outside this manual controller and on guarded existing paths.

`grid/data_boundary.h` uses a read-only synchronous sparse coordinate accessor, with explicit count/grant capped at 20,000. It validates the entire strictly ordered, unique, physically bounded inventory, including off-axis and explicitly unoccupied entries. Unavailable/invalid/over-grant input leaves output unchanged. Only APPLIED publishes a scalar selection; NOOP preserves output. Input/output alias is supported. Work is O(inventory), without allocation, coordinate-gap traversal, Page reads, query, dirty state or history changes. The adapter must supply the actual complete manual owner; the controller never infers absence from visible rows.

The pure release/sanitizer `data-boundary` plan passes in 3.266 seconds (`20261026T030725-feature-40011`) with all 15 catalogue contracts passing. Tests cover all directions and Shift variants against a direct coordinate-walk reference across 32 occupancy patterns, anchor reversals, isolated/contiguous/gapped/empty lanes, physical edges, full 20,000-entry inventory and atomic late-read/order/bounds/grant failure. Grid/App routing and actual hidden input remain separate acceptance children; no integrated C01 completion is claimed here.

## Checked Grid and App dispatch

Grid applies the manual controller only to finite cell shortcut-arrow input. Whole-axis and existing analytical navigation paths retain their routing. Far-column capacity is prepared transactionally before selection publication: all width/offset/name arrays are allocated first, original names and width prefix stay exact, and new tail columns are default/unnamed. Allocation failure changes neither selection nor the prior arrays. Existing capacity callers retain the fatal-allocation wrapper; the navigation path uses the checked result. The allocator fault hook is compiled only into the focused test binary and is absent from the production Grid object.

The App installs a stack-borrowed occupancy context only around synchronous input dispatch and clears it before arbitrary commands/replies. The callback resolves the current active owner first and rechecks document/sheet identity, sessions, revisions, request, array pointer, count and capacity before reading actual row/column coordinates. It never reads display text or a typed value layout. Source/object, busy/count, IO/history and proposed-source states remain excluded; no viewport result is used as sparse authority.

All 15 catalogue contracts pass, and symbol inspection confirms the production Grid object excludes the test allocator hook. The actual 31-stage hidden App workflow compiles and remains queued to root; it covers real modifier input at 100%/150%, format-only gaps, physical edges, selection reversal, editor focus, stale owner rejection, unchanged clocks/history/widths/jobs, and reopen.
