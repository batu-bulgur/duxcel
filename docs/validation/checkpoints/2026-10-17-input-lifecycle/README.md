## Result and ownership

The fast-flick bug had two paths. A spring could fight an ongoing pull or be extended again by a declining tail. After returning, small alternating inward/outward packets could also move the canonical worksheet fraction away from A1 and back, even with no visible elastic displacement. The shared grid now separates direct pull from return, holds a 32 CSS-point maximum cue and retains its return latch through momentum. A one-point accumulator at a genuinely returning boundary rejects alternating subpixel reversals while retaining the full distance of a coherent reversal. Deliberate 2/3-point inward movement and in-bounds momentum remain immediate.

macOS trackpads now supply actual logical-point deltas and Cocoa gesture phases through a once-per-frame, non-consuming UIContext snapshot. They bypass the mouse-wheel detent multiplier. The App supplies the current monotonic frame interval, avoiding the preceding frame's pacing duration. Browser WheelEvents use a bounded rate/quiet heuristic because they have no portable direct/momentum phase. Dark backing and the displaced row1/A edges remain visible. No input allocation, database query or new UI dependency was added.

Document Close and process Quit now differ. Cmd+W closes the Mac workbook surface, retains the process/menu/graphics host and suspends ordinary painting/query scheduling. New/Open/Dock reopen it; Cmd+Q takes the existing guarded termination path. Pending cell edits and save/discard/cancel are preserved. The browser leaves Ctrl/Cmd+W reserved and offers File/Alt→F→C: a dirty document can be cancelled or discarded into a clean, live surface. Browser Save remains disabled and the prompt defaults to Cancel.

Access keys now use supported English Excel sequences: F/H/N/A/W, Home 1/2/3, FF/FS/FC, AL/AC/AR, AN and CC, and Data SA/SD. Analyze Y, Visualization J and Z-prefixed commands are explicit Duxcel extensions. An ordered bounded queue preserves repeated letters within one frame, replaces duplicate native/GLFW events and rejects autorepeat. Native Option transitions remain ordered even when Option is released before H arrives in the same poll. Escape unwinds a prefix, tab hints and then the grid. Pointer File menus own editing input. Disabled actions remain disabled; this is not a complete or localized Excel command implementation.

The earlier trusted Alt failure was a CDP driver error: Windows virtual-key values were supplied as native macOS virtual-key codes. Chromium can synthesize an NSEvent from a nonzero native field and redispatch it through Cocoa. The driver now omits that field, uses rawKeyDown for non-text input and correct modifier transitions, and uses trusted keys throughout. Eight stress cycles and the new same-frame flows pass without the former DOM bypass. See the [Chromium input implementation](https://github.com/chromium/chromium/blob/150.0.7871.46/content/browser/devtools/protocol/input_handler.cc#L1147-L1182) and [Puppeteer's primary input implementation](https://github.com/puppeteer/puppeteer/blob/main/packages/puppeteer-core/src/cdp/Input.ts). The supported Excel mapping cites [Microsoft's keyboard guide](https://support.microsoft.com/en-us/accessibility/excel/keyboard-shortcuts-in-excel) and [365 Home keytips](https://support.microsoft.com/en-us/accessibility/media/excel-o365-win-keytips.png).

## CSV/demo roadmap groundwork

`fbc3ae1` extends native Page record IDs to concrete single-file raw CSV and generated demo sources. Identity is established before filtering/sorting, hidden metadata stays out of business schemas/copy/statistics/export, deterministic ties are shared, and observed file-version changes are rejected before publication. Changed/custom/grouped/multifile relations retain conservative fallback. Actual engine tests cover paging, duplicate values, exact typed sentinels and ownership. **Styles still do not follow source records.** S0/S2 selectors, asynchronous consumers and verified persistence remain open.

The separate worktree [measurement](csv-demo-performance.json) has its own [source/binary provenance](csv-demo-provenance.json): a 200,000-row/10.3 MB CSV and a 1,000,000-row generated demo, three warm samples per case. CSV first/deep medians were 58.936→59.857 ms and 104.800→99.129 ms. Deterministic CSV sort rose 103.047→116.718 ms. Demo deep offset rose 0.597→9.225 ms (+8.628 ms, 15.45×). This worker-side cost is retained explicitly; it is not an input/rendering speedup. Each variant uses one prepared Page statement and four fetches, with no extra SQL submission count.
